# Fish and Seafood

Fatty fish (salmon, mackerel, herring, sardines) are among the richest food sources of EPA+DHA omega-3s and vitamin D. Two portions of fatty fish per week is the general recommendation.

---

## Salmon (Wild)

- **Omega-3 type**: EPA + DHA (direct — no conversion needed)
- **Why eat**: Exceptional across B vitamins, omega-3, and vitamin D in a single food.

**Key nutrients**:

|---------|--------|---------------|
| Vitamin A | 70 mcg (per 100g) | ~10% |
| Vitamin D | 14.2 mcg (per 85g) | ~95% |
| Vitamin E | 4 mg (per portion) | ~27% |
| Vitamin B1 | 0.275 mg (per 100g) | ~25% |
| Vitamin B2 | 0.487 mg (per 100g) | ~44% |
| Vitamin B3 | 10 mg (per 100g) | ~71% |
| Vitamin B5 | 1.92 mg (per 100g) | ~38% |
| Vitamin B6 | 0.944 mg (per 100g) | ~73% |
| Vitamin B9 (folate) | 29 mcg (per 100g) | ~7% |

| Omega-3 (EPA+DHA) | 2,150 mg (per 100g) | — |
| Magnesium | 37 mg (per 100g) | ~12% |

- **Omega-3 type**: EPA + DHA
