# Fruits

---

## Avocado

- **Why eat**: Unique among fruits — rich in healthy fats (MUFAs), folate, B5, and fiber. One of the best plant sources of B9.
- **Fat type**: Mostly oleic acid (MUFA); supports heart health and fat-soluble vitamin absorption.

**Key nutrients** (per 1 avocado / ~135g without seed):

| Nutrient | Amount | % Daily Value |
|---------|--------|---------------|
| Vitamin E | 4.2 mg | ~28% |
| Vitamin K | 21 mcg (per 100g) | ~23% |
| Vitamin B1 | 0.1 mg | ~9% |
| Vitamin B2 | 0.19 mg | ~17% |
| Vitamin B3 | 2.6 mg (per 100g) | ~19% |
| Vitamin B5 | 2 mg | ~40% |
| Vitamin B6 | 0.39 mg | ~30% |
| Vitamin B9 (folate) | 121 mcg | ~30% |
| Fiber | 9.25g (70% insoluble) | ~37% |
| Magnesium | 39.4 mg | ~13% |
| Omega-6 | 1.8g (per 100g) | — |

## Blueberries

- **Why eat**: Rich in anthocyanins (give the blue/purple color) — antioxidants linked to reduced risk of type 2 diabetes, cardiovascular disease, and cognitive decline. Among the highest antioxidant density of any fruit.

**Key nutrients** (per 100g):

| Nutrient | Amount | % Daily Value |
|---------|--------|---------------|
| Vitamin C | 8.1 mg | ~11% |
| Vitamin K | 14 mcg (per 75g) | ~16% |

## Banana

- **Why eat**: Good B6 for protein metabolism; convenient fiber and magnesium source. Ripe bananas have higher simple sugar content; less ripe bananas have more resistant starch (lower GI).

**Key nutrients** (per 1 medium banana / ~110g):

| Nutrient | Amount | % Daily Value |
|---------|--------|---------------|
| Vitamin C | 10.3 mg | ~14% |
| Vitamin B5 | 0.4 mg | ~8% |
| Vitamin B6 | 0.433 mg | ~33% |
| Vitamin B9 (folate) | 23.6 mcg | ~6% |
| Fiber | 3g | ~12% |
| Magnesium | 31.9 mg | ~10% |

**Breakfast note**: banana + oats = ~40% B6
